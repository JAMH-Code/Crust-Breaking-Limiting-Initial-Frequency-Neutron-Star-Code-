# Crust-Breaking-Limiting-Initial-Frequency-Neutron-Star-Code-

This code is for the calculations for the paper "      ".

The code is done in Python using the libraries sympy, numpy, and pandas. In this repository, there is a Jupter Notebook file (.ipynb) and a python file (Same Code 

Different file type) containing all the code,

as well as the graphs used in the paper. Three graphs show the calculations done for 3 different solar masses of a Neutron Star. 

There is a 1.4, 1.6, and 2.0 solar mass graph. In the code, I symbolically represented the equations used in the paper. If there is a need 

for these equations feel free to use the code as you wish. The initial frequency is outputted when the code is run. 

In our caluations the value we used as the breaking strain is 0.1. If breaking strain in your specfic situion is different change the 0.1 in the code.
